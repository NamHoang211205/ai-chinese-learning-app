# Converso — AI-Powered Learning Companions Platform

Converso is a modern SaaS-style learning platform built with **Next.js (App Router)** and **Tailwind CSS**, designed to host interactive AI-powered learning companions. The long-term vision is to evolve Converso into a full-stack application that integrates real-time AI tutors, personalized learning journeys, and scalable backend services.

This repository currently focuses on the **front-end architecture, UI system, and design foundations**, following modern SaaS best practices.

---

## ✨ Features

- **Modern App Router architecture** using Next.js
- **Reusable UI components** (cards, grids, navigation, CTA sections)
- **Tailwind CSS v4** with custom design tokens and component layers
- **Responsive layouts** optimized for desktop and mobile
- **Custom theming** with CSS variables and dark mode support
- **Scalable project structure** prepared for backend and AI integration

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4 + custom CSS layers
- **UI Utilities:** clsx, class-variance-authority, tailwind-merge
- **Icons:** lucide-react
- **Fonts:** Google Fonts (Bricolage Grotesque)
- **Linting:** ESLint (Next.js Core Web Vitals)
